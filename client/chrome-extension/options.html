Bebok options

Point the extension at a running Bebok engine. Start one with cargo run -p bebok-server -- --port 8787 and paste the BEBOK_READY URL below (it carries the capability token when auth is on).

The project the agent works in (absolute path, as shown by the engine).

Set the same value as the engine's BEBOK_TOKEN env var. Stored locally, sent only to 127.0.0.1/localhost. With a stable token, Search local Bebok finds the engine on any port.

No URL handy? Search local Bebok probes the Engine URL above (or http://127.0.0.1:8787 when empty). It saves the address when the engine needs no token; otherwise it tells you to paste the fresh BEBOK_READY URL. A positive Test connection also saves both fields automatically.

Remote piloting

When enabled the extension registers with the engine and listens for remote commands (navigate, screenshot, evaluate, click, …) on your active tab. The agent can then drive your real browser.
