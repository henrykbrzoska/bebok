Bebok options

Point the extension at a running Bebok engine. Start one with cargo run -p bebok-server -- --port 8787 and paste the BEBOK_READY URL below (it carries the capability token when auth is on).

The project the agent works in (absolute path, as shown by the engine).

Remote piloting

When enabled the extension registers with the engine and listens for remote commands (navigate, screenshot, evaluate, click, …) on your active tab. The agent can then drive your real browser.
